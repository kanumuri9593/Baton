# Flutter launch lab

A small, credential-free sample for simulator runs, environment selection and screenshot review.

```sh
flutter create --project-name baton_lab --platforms=ios,android,web .
flutter pub get
flutter test
baton run "Local lab" --device <simulator-id>
```

The supplied widget test replaces Flutter's generated counter test. Complete the delivery and verify the status change. Use the Test lab target on another simulator to compare environment labels. See the repository launch guide for branch/worktree and proof examples.

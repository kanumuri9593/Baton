Why Baton?

Stop spending agent credits on terminal babysitting. Get structured controls and evidence.

⚡

Real Hot Reload

Baton drives Flutter's daemon protocol directly — hot reload is one request, not a terminal scrape. Web frameworks get HMR-aware restart detection.

📱

Multi-Device

Run three simulators at once. Boot iOS devices by name, not a generic "start simulator." Pick a branch and Baton makes a worktree — no stash, no switch.

🎯

Honest Capabilities

A Vite session doesn't claim Flutter's stateful hot reload. Agents get clear refusals instead of silent no-ops. Every capability is reported truthfully.

🔍

Structured Errors

Failed reloads return the actual compiler error, not just "DevFS synchronization failed." Agents can fix their own mistakes without guessing.

📸

Screenshot Evidence

Capture what the app actually shows. The agent can edit a widget, hot reload, screenshot, and see whether it worked — no IDE, no manual clicking.

🖥️

Floating HUD

Native floating panel on macOS, chromeless browser elsewhere. Stays above full-screen terminals, never steals focus, remembers where you put it.

The Agent Loop

Baton gives your agent a feedback loop that doesn't exist in an IDE.

Typical agent workflow 
inspect_project  → discover targets and devices
run_target       → start the app on a simulator
wait_for         → block until ready (no polling)
... exercise the app with browser/device tools ...
screenshot       → capture evidence
read_logs        → structured output, not terminal scraping
... edit code ...
hot_reload       → 87ms, compiler errors if it fails
screenshot       → verify the change worked

No IDE can offer this — the agent isn't holding the mouse.

Get Started

Install Baton and wire it into your agent in under a minute.

Install from GitHub 
# Global install (requires Node 24+)
npm install -g github:kanumuri9593/Baton

# Or one-shot without install
npx -y --package=github:kanumuri9593/Baton baton list
Add to your MCP client config 
{
  "mcpServers": {
    "baton": { "command": "baton-mcp" }
  }
}
